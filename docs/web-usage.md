# Web 使用手册

建议使用 Chrome 或 Edge 打开 Turnline。首次发起语音通话时，请在浏览器弹窗中允许访问麦克风。安装与启动见 [快速开始](../README.md#快速开始)，连接 PipiClaw、HTTPS 与口令配置见 [连接与部署](deployment.md)。

## 发起与控制通话

点击「开始通话」即可开麦。通话区中央的光球会随收音与播报音量实时律动，后端思考较久时会切换为等待动画。

- **实时字幕与发送**：开口后界面即时显示草稿字幕。默认在停顿后自动发送，也可以直接点击光球立即发送；点击通话区右上角的模式标签（`自动断句` / `按住说话`）可快速打开输入设置。
- **打断播报**：助手说话时，点击光球或「停播」按钮即可停止语音，工作和文字回复会继续；桌面端也可以按 `Esc`。若希望直接靠开口打断，可在通话设置中开启「允许在播报时开口打断」（默认关闭，以避免环境噪声误触发）。
- **任务中补充指令**：在服务端中转模式下，助手工作进行中可以直接开口或打字补充。Turnline 会先停播，并将补充内容插入当前回合；PipiClaw 确认接收后，消息下方会显示「已插入正在进行的工作」。
- **停止当前工作**：点击对话记录上方的「停止工作」可取消当前回合。通话中如果识别到单独一句「停止工作」，同样会触发取消并给出确认提示。
- **挂断与离页不中断任务**：挂断只关闭语音通话。在服务端中转模式下，已提交的回合在刷新页面、切换会话或关闭标签页后仍会继续运行，重新打开原会话即可续接剩余进展与回复。浏览器直连使用 PipiClaw 的 HTTP 后台响应，补充消息会等待上一轮结束。

## 通话设置

点击页面右上角的齿轮图标打开「通话设置」，所有偏好均保存在当前浏览器本地：

| 分组 | 设置项 | 可选项（粗体为默认） | 说明 |
| --- | --- | --- | --- |
| 语音输入 | 语音输入 | **自动断句** / 按住说话 | 「按住说话」模式下，桌面按住 `Space`、手机按住光球说话，松开即发送。 |
| 语音输入 | 反应速度 | 灵敏 / **均衡** / 耐心 | 控制停顿多久后自动提交。「均衡」在完整句后较快接话，遇到「然后」「比如」等未说完的表达会自动多等片刻。 |
| 语音输入 | 最短有效语音 | 0 秒 / 1 秒 / **2 秒** / 3 秒 / 5 秒 | 单轮累计有声时长达到该值才送交转写，静音不计入，句中停顿可合并到同一轮。设为 0 秒即关闭过滤。按住说话和立即发送同样遵循此项。 |
| 语音播报与反馈 | 播报时机 | **流式播报** / 确认正文后播报 | 流式播报在收到首个短分句后即朗读；确认模式会等段落性质明确后再出声，避开中间进度句。 |
| 语音播报与反馈 | 播报语速 | 0.9× / **1.0×** / 1.07× / 1.15× | 调整语音播报节奏。 |
| 语音播报与反馈 | 思考音与提示音 | **开启** / 关闭 | 可分别开关「等待较久时播放思考音」与「播放通话提示音」。 |
| 语音播报与反馈 | 允许在播报时开口打断 | 开启 / **关闭** | 开启后可在播报过程中直接开口插话，系统会先暂停播报，确认有效语音后彻底停播。嘈杂环境建议关闭。 |
| 补充指令 | 补充通话指令 | 自定义文本（上限 3000 字） | 附加到每轮请求的指令，例如「每次只说一个步骤」。 |

## 文字对话与历史会话

Turnline 将语音和文字统一在同一条对话时间线里：

- **随时打字与静音阅读**：底部输入框常驻可用，空对话时也可直接点击示例问题快速开聊；手机通话界面可点键盘图标唤出输入。若这一轮只想看字不想听播报，点输入框旁的扬声器图标关闭本轮朗读后再发送。
- **消息操作与朗读高亮**：播报过程中，对话记录会高亮当前正在朗读的句子，并在被打断时标出断点。每条回复均支持复制文字、重新朗读或让助手重新回答。
- **工作进度与推理摘要**：执行耗时任务时，对话记录上方会实时显示工作耗时、工具调用次数与当前操作；展开可查看工具调用列表、结果预览以及 PipiClaw 返回的推理摘要。
- **历史会话**：对话内容由 PipiClaw 持久保存。点击「历史」可切换会话、点击「新对话」开启新会话，刷新页面后会自动恢复当前会话。口令模式下，同一 Turnline 实例的已解锁设备共享中转会话历史；免口令模式按浏览器隔离；浏览器直连则按 PipiClaw 地址分别记住本机打开过的会话。

## 界面细节、口令解锁与快捷键

- **深浅主题、展开阅读与 PWA**：首次访问跟随系统深浅色模式，点击页首图标可手动切换并记住选择。对话记录区支持一键展开以方便阅读长文。在 Chrome 中选择「添加到主屏幕」或「安装应用」，即可将 Turnline 作为独立窗口使用。
- **口令解锁与退出**：若服务端启用了 `--auth passcode`，首次打开页面会弹出「访问验证」窗口，输入访问口令解锁后即可正常通话与发消息；有效期内刷新或重新打开 PWA 无需重复输入。若会话过期或被服务端吊销，页面会停止重连并提示重新解锁；需要主动登出时，可在右上角「通话设置」底部点击「退出此设备」。连续输错口令会触发冷却倒计时，待结束后再重试。服务端管理方式见 [连接与部署](deployment.md#访问控制与会话管理)。
- **键盘快捷键**（桌面端按 `?` 可随时查看）：

| 快捷键 | 作用 |
| --- | --- |
| `Space` | 按住说话，松开发送（按住说话模式） |
| `M` | 静音 / 取消静音 |
| `Esc` | 停播或关闭弹窗 |
| `/` | 聚焦底部文字输入框 |
| `Enter` | 发送文字消息（`Shift` + `Enter` 换行） |
| `Ctrl` / `⌘` + `Enter` | 发送文字消息 |

## 通话诊断

点击通话区右上角的信息图标，可打开「通话诊断」面板，实时查看从点击到可说话、停说到提交、请求到首字与首声、播报间隙等逐阶段耗时，并支持导出逐轮计时 JSON（仅包含计时、状态与响应 ID，不含对话正文），便于排查延迟或回声问题。各字段口径见 [测试手册](testing.md#诊断计时口径)。

## 语音合成说明

Turnline Web 默认在服务端使用 `matcha-icefall-zh-en` 与 Vocos 声码器：中文沿用模型的数字、日期与时间归一化规则并转成拼音，英文通过 eSpeak NG 转为音素，型号与版本号按统一结构规则处理，最终拼入同一条音素序列由同一个音色流式合成。技术细节见 [项目架构](architecture.md)，上游模型与示例可参考 [Matcha 中英模型页](https://k2-fsa.github.io/sherpa/onnx/tts/all/Chinese-English/matcha-icefall-zh-en.html) 与 [Sherpa-ONNX 音素输入示例](https://github.com/k2-fsa/sherpa-onnx/blob/v2.0.3/python-api-examples/test-offline-tts-matcha-zh-en-phonemize.py)。
