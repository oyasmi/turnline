# Web 使用手册

使用 Chrome 或 Edge 打开 Turnline。说话前，在浏览器提示时允许访问麦克风。首次启动见[快速开始](../README.md#快速开始)，连接 PipiClaw 及配置 HTTPS 见[连接与部署](deployment.md)。

## 通话操作

- 默认「均衡」会在完整句后较快接话，遇到「然后」等没说完的表达会多等一会儿。通话设置提供「灵敏」「均衡」「耐心」三档。
- 说话时会出现实时字幕。停顿后自动发送，也可以点光球立即发送。光球跟随输入和播报音量，等待较久时会显示思考动画。
- 「通话设置 → 最短有效语音」默认为 2 秒。每轮累计检测到的有声时长，达到设定值才开始转写。句中停顿可以合并到同一轮，静音不计入时长。可选 0 秒（关闭）、1 秒、2 秒、3 秒或 5 秒。按住说话和立即发送也使用这个设置。
- 默认流式播报，收到短分句即可开始合成。设置里可以改为确认正文后播报、调整语速或关闭提示音。后端等待较久时，光球会提示等待状态，也可播放轻柔的思考音。思考音能单独关闭。
- 播报时可点光球或「打断」。开口打断默认关闭，可在通话设置打开。网络短暂断开时语音通道会尝试自动恢复。挂断后仍可在同一会话发文字或查看后台任务结果。
- 对话保存在 PipiClaw。中转模式自动创建浏览器会话，隔离各浏览器的对话记录。PipiClaw 接收麦克风的转写文字。
- 在「对话记录 → 历史」选择旧会话即可接着聊，刷新后会打开选中的会话。浏览器直连按 PipiClaw 地址保存已打开的会话 ID。
- 首次访问跟随系统主题，页首图标可以切换并记住选择。输入框常驻，手机通话中的键盘按钮可聚焦输入框，对话记录支持展开。用 Chrome 的「添加到主屏幕」可单独打开 Turnline。
- 设置里可选择「按住说话」。桌面按住空格、手机按住光球，松开发送。桌面另支持 `M` 静音、`Esc` 打断、`/` 聚焦输入框，按 `?` 查看快捷键。
- 对话记录会标出当前正播的句子和打断位置，也能复制文字、重播回复或请助手重新回答。若这一轮只想阅读，点输入框旁的扬声器图标再发文字。
- 通话区右上角的诊断按钮可导出点击到可说话、请求到首字各阶段，以及播报和打断计时。

## 语音模型

默认使用 `matcha-icefall-zh-en` 与 Vocos。中文沿用模型的数字、日期和电话归一化规则，再用 pypinyin 转成拼音。英文用 eSpeak NG 转成音素，字母数字混合的型号和版本号使用统一的结构规则。中英文在同一份音素序列中送给 Matcha，使用同一个音色。

- [Matcha 中英模型和上游样音](https://k2-fsa.github.io/sherpa/onnx/tts/all/Chinese-English/matcha-icefall-zh-en.html)
- [Sherpa-ONNX 中英混读音素输入示例](https://github.com/k2-fsa/sherpa-onnx/blob/v2.0.3/python-api-examples/test-offline-tts-matcha-zh-en-phonemize.py)
